# Thief2-newdark

Reverse-engineering / hacking work on the Thief II NewDark engine binary: head-tracking, stereo and a SteamVR
headset mode (`headlook/`, `d3d9proxy/`), plus XInput controller support (`xinput_joy/`).

All project history, findings, and progress are tracked in [docs/DEVLOG.md](docs/DEVLOG.md) (the development
log; it was README.md until 2026-09-25). Always read docs/DEVLOG.md first for current context before starting
work, then [docs/HANDOFF.md](docs/HANDOFF.md), and update the log as work progresses (new findings, tools used,
session log entries).

`README.md` is now the short, player-facing description of the mod and `docs/HOW_IT_WORKS.md` the technical
overview for other modders. Keep both current when features, controls, settings or install steps change, but put
history and evidence in the log, not there.
